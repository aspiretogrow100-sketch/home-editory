# Compact “Make the room yours” studio

## Goal
Fit the initial room-design step into one desktop screen as closely as practical, while keeping every choice easy to scan and use.

## Changes
- Compress the section heading, step navigation, card spacing, and option heights.
- Turn the introductory sidebar into a slimmer in-panel progress summary so it does not add page height.
- Keep longer option sets inside a clearly scrollable choice area, while navigation buttons remain visible.
- Preserve all existing wizard choices, generation logic, payments, and generated results.
- On mobile, use compact horizontal step navigation and natural page scrolling to avoid cramped controls.

## Verification
- Check the first wizard step at desktop and mobile sizes.
- Confirm the desktop studio stays near one viewport and all controls remain usable.
